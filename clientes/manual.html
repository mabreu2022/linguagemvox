1. Rodar o Programa MVC no Terminal (Console)

Executa a aplicação no padrão Model-View-Controller com persistência em clientes/db/clientes_vox.db.

Comando Recomendado (via script NPM) Recomendado
$npm run crud:mvc
Executa automaticamente o interpretador Vox carregando o arquivo de entrada clientes/app.vox.
Comando Direto (via CLI do Compilador Vox)
$node dist/cli/index.js run clientes/app.vox
Útil caso queira invocar o binário do compilador diretamente sem o NPM.

2. Rodar a Aplicação no Navegador Web

Inicia o servidor HTTP nativo com API REST e abre a dashboard interativa com glassmorphism e busca dinâmica.

Passo 1: Iniciar o Servidor Web Recomendado
$npm run crud:web
Inicia o servidor na porta 3000 conectado à base SQLite em clientes_vox.db.
Passo 2: Abrir no Navegador
http://localhost:3000
Ou abra diretamente pelo terminal PowerShell com o comando abaixo:
$Start-Process "http://localhost:3000"
Recurso Web Como Usar Efeito
+ Novo Cliente Clique no botão azul superior Abre modal de cadastro com validações
Busca Dinâmica Digite na barra de pesquisa Filtra por Nome, E-mail ou Cidade em tempo real
Editar (Lápis) Clique no botão na linha da tabela Abre modal preenchido para alterar telefone ou saldo
Excluir (Lixeira) Clique no botão vermelho da linha Abre confirmação e remove o registro do SQLite
Exportar CSV Clique no botão da barra superior Faz o download da planilha de clientes instantaneamente

3. Gestão do Banco de Dados SQLite

Localização dos arquivos de banco de dados e rotinas de manutenção.

Arquivo Finalidade Status
clientes/db/clientes_vox.db Banco de dados oficial utilizado pela arquitetura MVC Ativo & Persistente
clientes_vox.db Banco de dados utilizado pelo servidor Web Dashboard Ativo & Persistente
Sincronizar / Copiar o Banco Atualizado para a pasta MVC:
$Copy-Item "clientes_vox.db" -Destination "clientes/db/clientes_vox.db" -Force

4. Utilitários & Compilador da Linguagem Vox

Comandos úteis do compilador Vox para desenvolvimento, verificação de tipos e compilação nativa.

Recompilar o Compilador Vox (TypeScript ➔ JavaScript):
$npm run build
Verificar Sintaxe e Tipos sem Executar (Type Check):
$node dist/cli/index.js check clientes/app.vox
Executar a Suíte de Testes Automatizados:
$npm test
Compilar Código Vox para Executável Nativo (.exe via C99):
$node dist/cli/index.js build examples/phase6_native.vox -o app.exe --run
