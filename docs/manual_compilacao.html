Manual Oficial de Compilação & Geração de .EXE

Guia completo de arquitetura, funcionamento do transpilador ANSI C99, pipeline de ligação nativa PE/COFF de 64 bits, compiladores C integrados (TCC, MSVC, GCC, Clang) e geração de executáveis nativos no Vox Studio RAD.

Linguagem Vox v1.1 (Delphi-Rust Modern)
IDE RAD Vox Studio RAD 1.0
Alvo Nativo Windows x86_64 (.EXE)
Compilador Padrão TCC v0.9.27 (Embutido)
Velocidade de Build ~105ms a 250ms

1 Respostas Diretas às Dúvidas Centrais

Abaixo estão as respostas técnicas e precisas sobre o comportamento de compilação da IDE:

🪟
A IDE faz .EXE de verdade?
SIM. A IDE possui gerador de código nativo que produz binários executáveis reais do formato PE32+ (x86_64) de 64-bit para Windows, gravados na pasta bin/windows/<Projeto>.exe.
⚙️
Como ela compila?
Através de um pipeline de 2 estágios: o compilador Vox faz a análise sintática e tipagem, transpila o código para ANSI C99 otimizado e invoca um compilador C nativo para gerar o .exe.
⚡
Qual tecnologia utiliza?
Transpilador baseado em AST (TypeScript), cabeçalho de suporte C (vox_runtime.h) com RAII, gerenciamento de strings, coleta de memória e interface Win32 API.
🛠️
Qual compilador C é utilizado?
Possui detecção inteligente com prioridade: Tiny C Compiler (TCC) embutido (padrão zero-dependência), MSVC (Visual Studio), GCC (MinGW) ou LLVM Clang.
✔
Validação Prática Realizada com Sucesso Compilamos com sucesso o projeto VoxERP_Comercial.exe em apenas 105ms usando o TCC embutido, gerando o executável de 3.072 bytes na pasta d:\Projetos AntiGravity\VOXIDERAD\bin\windows\VoxERP_Comercial.exe e testando sua execução autônoma no Windows!

2 Os Três Modos de Execução da IDE (Diferença Crucial)

Muitos desenvolvedores estranham não ver o .exe ao clicar em executar ou ao olhar na pasta dist/web-app/. Isso acontece porque o Vox Studio RAD oferece três alvos distintos, cada um com propósito específico:

Modo Como Funciona Pasta de Saída Formato do Resultado Finalidade
1. F9 (Live Form Runner) Execução interpretada / ao vivo da interface VCL dentro da IDE ou via Electron WebView2. Memória / Cache local Janela de Teste RAD Instantânea Prototipação em tempo real (0ms de espera), teste de layout, DBGrid e eventos sem compilar.
2. Web App (HTML5 + REST) Transpilação do formulário e código em uma aplicação Web completa (HTML5, JS, Node.js). dist/web-app/ index.html, server.js, pacotes Publicação em servidores de intranet, nuvem, containers Docker ou acesso via navegador.
3. Compilação Nativa Windows Transpilação para ANSI C99 e compilação binária nativa via compilador C (TCC / MSVC / GCC). bin/windows/ <Projeto>.exe (Binário 64-bit) Distribuição para usuários finais, instalação local, máximo desempenho nativo.
💡
Por que a pasta dist/web-app/ não tinha .exe? A pasta dist/web-app/ é exclusivamente o diretório de destino do Modo 2 (Web Browser). O executável nativo do Windows fica localizado em bin/windows/ quando você ativa o Modo 3 (Windows 64-bit Native EXE) na barra de ferramentas da IDE!

3 O Pipeline Completo de Compilação (Passo a Passo)

O compilador Vox não gera bytecode nem necessita de máquina virtual pesada (como JVM ou .NET CLR) para rodar o executável nativo. Ele utiliza a técnica moderna de Source-to-Source Compilation (Transpilação para C99 + Compilação Nativa):

1
Código Fonte Vox (.vox)
Código Pascal/Delphi-Like com sintaxe moderna (classes, traits, structs, closures, try/catch, SQL embutido).
↓
2
Lexer, Parser & AST
O parser sintático constrói a árvore abstrata (AST) e o validador de tipos verifica contratos e assinaturas.
↓
3
Gerador C99 (c_generator.ts)
Converte as estruturas de controle, tipos primitivos, rotinas RAII drop() e dispatch de métodos para ANSI C puro.
↓
4
Inclusão do Runtime C (vox_runtime.h)
Anexa a biblioteca de runtime (912 linhas de C) que implementa strings dinâmicas (vox_str), buffers, arrays e chamadas Win32.
↓
5
Compilador C Nativo (TCC / MSVC / GCC)
O compilador C transforma o código ANSI C em código de máquina x86_64, resolvendo símbolos e efetuando a link-edição.
↓
6
Binário Final Gerado (bin/windows/<Nome>.exe)
Executável nativo portátil de 64 bits pronto para execução direta com duplo-clique no Windows sem dependências!

Estrutura dos Tipos Vox Mapeados para C

O gerador de código C (src/codegen/c_generator.ts) faz a correspondência direta entre os tipos de alto nível da linguagem Vox e os tipos de código de máquina do C ANSI:

Tipo Vox Tipo C Equivalente Tamanho / Representação
int int64_t (vox_int) Inteiro com sinal de 64 bits
float double (vox_float) Ponto flutuante de precisão dupla (64 bits)
bool bool (vox_bool) Booleano de 1 byte (true / false)
string vox_str* Estrutura dinâmica com ponteiro de caracteres e size_t len
classe / struct typedef struct { ... } Estrutura alocada com ponteiros e tabela de métodos
try / catch / throw setjmp / longjmp Pilha de frames protegidos para tratamento de exceções

4 Os Compiladores C Suportados e Algoritmo de Detecção

O Vox Studio RAD possui uma classe centralizadora de compilação chamada Compiler (localizada em d:\Projetos AntiGravity\linguagem\src\codegen\compiler.ts). Quando você solicita a compilação de um projeto, o método detectCompiler() pesquisa o sistema na seguinte ordem de prioridade:

1º — Tiny C Compiler (TCC) [Embutido]
Localização: tools/tcc/tcc.exe
Prioridade: Máxima no Windows.
Vantagens: Extremamente leve (< 3 MB), compilação quase instantânea (~100ms), já vem dentro da pasta da IDE. O usuário não precisa ter nenhum compilador instalado na máquina!
2º — Microsoft Visual C++ (MSVC / cl.exe)
Localização: Visual Studio 2019 / 2022 (Build Tools)
Invocação: vcvars64.bat && cl /O2 /utf-8 ...
Vantagens: Máxima otimização de código para processadores Intel/AMD modernos, geração de binários de produção para alto desempenho.
3º — GNU Compiler Collection (GCC)
Localização: MinGW-w64 no PATH do Windows ou GCC no Linux.
Invocação: gcc -std=c99 -Wall -O2 -lm
Vantagens: Padrão industrial amplamente testado e utilizado em ambientes cross-platform.
4º — LLVM Clang
Localização: Clang no PATH do sistema.
Invocação: clang -std=c99 -Wall -O2 -lm
Vantagens: Diagnósticos avançados de código e excelente otimização intermediária LLVM.
Trecho do Código de Detecção — src/codegen/compiler.ts TypeScript 
// 1. TCC local/embutido no projeto
const candidateTccPaths = [
  path.resolve(process.cwd(), "tools", "tcc", "tcc.exe"),
  path.resolve(__dirname, "..", "..", "tools", "tcc", "tcc.exe"),
  path.resolve(__dirname, "..", "tools", "tcc", "tcc.exe"),
];

for (const tccPath of candidateTccPaths) {
  if (fs.existsSync(tccPath)) {
    const out = child_process.execSync(`"${tccPath}" -v`, { encoding: "utf-8" }).trim();
    this.cachedCompiler = {
      type: "tcc",
      path: tccPath,
      name: "Tiny C Compiler (TCC)",
      version: out.split("\n")[0],
    };
    return this.cachedCompiler;
  }
}

5 Por Que o TCC (Tiny C Compiler) É Tão Revolucionário?

O Tiny C Compiler (TCC) é um dos compiladores C mais rápidos do mundo, criado por Fabrice Bellard. No Vox Studio RAD, ele foi adotado como o compilador nativo de distribuição por motivos estratégicos:

🚀 Velocidade Extrema
Enquanto um compilador tradicional leva de 3 a 10 segundos para inicializar includes e linkar um binário, o TCC compila todo o código intermediário do Vox e gera o .exe em apenas 105 a 130 milissegundos.
📦 Zero Dependências
O usuário final que baixa e instala o instalador do Vox Studio RAD não precisa instalar o Visual Studio (que tem mais de 10 GB) nem o MinGW. O TCC tem apenas 2 MB e já vem pré-configurado!
🛡️ Binários Autônomos
O executável gerado pelo TCC é um arquivo .exe independente de 64-bit que roda em qualquer computador com Windows 10 ou 11 sem exigir pacotes redistribuíveis (VC++ Redistributable).

Etapa 2: Selecionar o Alvo Windows 64-bit Na barra de ferramentas superior (ao lado do botão do GitHub), clique no dropdown de plataformas onde está escrito 🌐 Web Browser (HTML5 + REST) e mude para:

7 Compilação via Linha de Comando (CLI)

Você também pode compilar qualquer arquivo de código fonte Vox diretamente através do terminal de comandos sem abrir a interface gráfica da IDE:

Compilar para EXE via Terminal (PowerShell / Prompt) Bash / PowerShell 
# Sintaxe básica de compilação
vox build meu_programa.vox -o meu_programa.exe

# Compilar e executar imediatamente
vox build meu_programa.vox -o meu_programa.exe --run

# Compilar com otimizações de produção (-O2)
vox build sistema.vox -o sistema.exe --opt

# Emitir o arquivo C intermediário gerado para inspeção
vox build sistema.vox -o sistema.exe --emit-c

8 Compilação Remota Cruzada para Linux 64-bit

Além do Windows, o Vox Studio RAD possui um sistema integrado de compilação remota via SSH para Linux 64-bit (Ubuntu, Debian, CentOS).

Ao selecionar 🐧 Linux 64-bit (Remote SSH / IP) na barra de ferramentas:

  1. A IDE transpila o código Vox para C99 na sua máquina local;
  2. Conecta-se automaticamente via SSH ao servidor Linux configurado (ex: 192.168.1.150);
  3. Transfere o código C e o cabeçalho vox_runtime.h para o diretório remoto /tmp/vox_build;
  4. Compila no servidor remoto com o gcc do Linux gerando um binário nativo ELF de 64 bits;
  5. Permite rodar o programa remotamente com o output exibido no terminal da IDE ou baixar o binário para sua máquina.

9 Diagnóstico & Resolução de Problemas Frequentes

Problema / Sintoma Causa Provável Solução Recomendada
Fui na pasta dist/web-app/ e não achei o .exe. A pasta dist/web-app/ é o destino da aplicação Web (HTML5/JS), não de executáveis Windows. O executável nativo é gerado na pasta VOXIDERAD/bin/windows/ ao selecionar a plataforma Windows 64-bit (Native EXE).
Ao teclar F9 a tela ficou em "Carregando dados da aplicação...". Erro em tempo de execução no componente DBGrid ao inicializar estado sem binding. Bug corrigido no runner.js. Pressione Ctrl + F5 no navegador e tecle F9 novamente.
Erro "Nenhum compilador C encontrado". A pasta tools/tcc não foi encontrada ou não está no diretório de trabalho. O TCC agora está embutido tanto na pasta linguagem/tools/tcc quanto em VOXIDERAD/tools/tcc.
A barra de ferramentas só mostrava Web e não mostrava Windows. O navegador estava exibindo uma versão antiga do HTML armazenada em cache. Pressione Ctrl + F5 no navegador para forçar a atualização do layout da IDE.

10 Como Exportar este Manual para PDF

Este manual foi integralmente formatado com regras avançadas de diagramação impressa CSS (@media print) no padrão Folha A4:

📄
Instruções para Exportação:
