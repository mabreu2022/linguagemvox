Este livro é a referência definitiva para estudantes, arquitetos de software e desenvolvedores de sistemas que desejam dominar a linguagem Vox, combinando a alta velocidade de execução do C com a ergonomia, segurança de tipos e clareza das linguagens modernas.

Introdução

Prefácio: A Gênese e Filosofia do Vox

Durante décadas, a engenharia de software foi forçada a escolher entre dois mundos polarizados: de um lado, linguagens de sistemas clássicas como C e C++, que oferecem controle absoluto de memória e desempenho sem concessões, mas cobram um preço altíssimo em erros humanos fatais (como buffer overflows, segmentation faults e vazamentos de memória); do outro lado, linguagens de alto nível dotadas de coletores de lixo (Garbage Collectors) pesados, que compram segurança sacrificando a previsibilidade temporal, consumindo gigabytes de memória e introduzindo pausas aleatórias no runtime.

A linguagem Vox nasceu para dissolver esse falso dilema. Seu objetivo primordial é propiciar:

  • Velocidade de C99 pura: Compilação direta para C padronizado ISO/IEC 9899:1999, gerando executáveis que iniciam em menos de 1 milissegundo e consomem poucos megabytes.
  • Segurança de Memória Afim: Um modelo de posse (Affine Ownership) e checagem de empréstimo (Borrow Checker) que impede ponteiros pendentes e liberações duplas em tempo de compilação, sem depender de Garbage Collector de pausa total.
  • Concorrência CSP Segura: Corotinas leves disparadas com spawn e canais tipados, permitindo que threads comuniquem dados sem criar condições de corrida (data races).
  • Ergonomia e Simplicidade: Uma sintaxe elegante, inspirada no melhor de TypeScript, Rust e Go, eliminando herança clássica frágil em favor de Composição e Traits.
🏛️ Decisão de Arquitetura: Por que C99 como Alvo?

Ao gerar código fonte em C99 intermediário, o compilador Vox se beneficia instantaneamente de mais de 50 anos de engenharia de compiladores e otimizadores industriais (GCC, Clang e MSVC), rodando em qualquer CPU existente no planeta, desde supercomputadores x86_64 e ARM64 até pequenos microcontroladores embarcados.

Capítulo 01

O Que é o Vox? Filosofia e Arquitetura

O Vox é uma linguagem compilada de tipagem estática e gradual, projetada para a construção de sistemas modernos de alta confiabilidade. Ela opera sob o paradigma de abstrações de custo zero (zero-cost abstractions): nenhuma funcionalidade de alto nível do Vox impõe penalidade de runtime se você não a utilizar.

O Pipeline do Compilador

Quando você executa o comando vox build main.vox, seu código passa por cinco estágios sequenciais rigorosos:

  1. Análise Léxica (Lexer): O código-fonte bruto em texto é convertido em um fluxo de tokens tipados.
  2. Análise Sintática (Parser): O fluxo de tokens é transformado em uma Árvore Sintática Abstrata (AST - Abstract Syntax Tree).
  3. Análise Semântica e Borrow Checker: O compilador valida tipos, resolve escopos de identificadores e checa a árvore de posse de memória afim.
  4. Geração de Código C99: A AST validada é transpilada para C99 idiomático de alta performance, incluindo o runtime leve vox_runtime.h.
  5. Montagem do Binário Nativo: O compilador de C local (GCC, Clang ou MSVC) gera o executável final de máquina (.exe no Windows, binário ELF no Linux).
TERMINAL 
$ vox check app.vox    # Valida tipos e ownership em 15ms
$ vox build app.vox -O3 # Gera app.exe nativo hiperotimizado
$ ./app                 # Executa diretamente na CPU
Capítulo 02

Instalação, Ambiente e o Primeiro Programa

Iniciar com o Vox é um processo imediato. A ferramenta unificada de linha de comando gerencia todas as etapas do ciclo de vida:

Comando Finalidade Exemplo de Uso
vox run <arquivo> Executa o arquivo imediatamente via interpretador vox run main.vox
vox build <arquivo> Compila para executável binário nativo (.exe) vox build main.vox -o app
vox check <arquivo> Realiza análise semântica e do borrow checker sem gerar binário vox check main.vox
vox test Executa a suíte de testes unitários do projeto vox test
vox repl Abre o console iterativo de experimentação rápida vox repl

Seu Primeiro Programa: Olá, Mundo!

Crie um arquivo chamado ola.vox com o seguinte conteúdo:

VOX — ola.vox 
/// Ponto de entrada canônico de um programa Vox
fn main() {
    println!("Olá, Mundo! Bem-vindo à linguagem Vox v1.0.");
}

Execute o programa diretamente pelo terminal:

TERMINAL 
$ vox run ola.vox
Olá, Mundo! Bem-vindo à linguagem Vox v1.0.

Anatomia do código: A palavra-chave fn declara uma função. A função main() é o ponto de partida onde o sistema operacional transfere a execução. A macro println! (notada pelo ponto de exclamação no final) é uma macro embutida do compilador que formata o texto e envia a string diretamente para a saída padrão (stdout), acrescentando quebra de linha.

Capítulo 03

Variáveis, Constantes e Imutabilidade por Padrão

Um dos maiores causadores de defeitos em softwares é o estado compartilhado mutável concorrente. Para erradicar essa classe inteira de falhas, o Vox adota imutabilidade por padrão.

Declaração com let

Quando você vincula um valor a um nome utilizando a instrução let, essa ligação é imutável:

VOX 
let limite: int = 100;
// limite = 200; // <-- ERRO DE COMPILAÇÃO!

Caso você tente reatribuir uma variável declarada com let, o compilador emitirá o erro semântico [E0106] antes que qualquer código possa ser executado:

❌ Erro Semântico E0106
[E0106]: Cannot reassign immutable variable 'limite'. Tip: Declare it as 'let mut limite' if mutation is intended.

Mutabilidade Explícita com let mut

Se a variável precisa ter seu valor alterado no decorrer do algoritmo, a palavra-chave mut deve ser expressa de forma clara:

VOX 
let mut contador: int = 0;
contador = contador + 1;
println!("Contador atual: " + (contador as str));

Constantes com const

Constantes são sempre imutáveis, devem ser explicitamente tipadas e calculáveis em tempo de compilação. Por convenção, seus identificadores utilizam letras maiúsculas:

VOX 
const TAXA_PADRAO: float = 0.15;
const NOME_SISTEMA: str = "Vox Core Engine";

Escopos em Bloco e Shadowing

Variáveis declaradas dentro de um par de chaves { ... } existem apenas dentro daquele bloco:

VOX 
let x = 10;
{
    let x = 20; // Shadowing: oculta o x externo temporariamente
    println!("x interno: " + (x as str)); // 20
}
println!("x externo: " + (x as str)); // 10
Capítulo 04

Sistema de Tipos Gradual e Primitivos

O Vox possui um sistema de tipos estático e robusto com inferência de tipos bidirecional. Você pode anotar os tipos explicitamente ou permitir que o compilador deduza o tipo com base no valor atribuído.

Tipo Primitivo Descrição Exemplo Literal
int Inteiro de 64 bits com sinal (-9.223.372.036.854.775.808 a 9.223.372.036.854.775.807) 42, -1500, 0
float Ponto flutuante IEEE-754 de precisão dupla (64-bit) 3.14159, -0.005, 2.0
bool Booleano lógico estrito true, false
str Cadeia de caracteres UTF-8 gerenciada e imutável "Vox Language"
char Ponto de código de caractere Unicode de 32 bits 'A', 'λ', '€'
void Ausência de valor (retorno de procedimentos sem resultado) fn log(): void
any Tipo dinâmico para interoperabilidade gradual Qualquer valor

Coerção e Conversão Explícita de Tipos com as

Ao contrário de C, o Vox nunca realiza coerção implícita com perda de precisão entre tipos numéricos. Se você tentar somar um int com um float, o compilador exigirá a conversão explícita através da palavra-chave as:

VOX 
let quantidade: int = 5;
let preco_unitario: float = 19.90;

// Conversão segura e explícita:
let total: float = (quantidade as float) * preco_unitario;
println!("Total calculado: " + (total as str));
Capítulo 05

Operadores e Expressões

O Vox oferece um conjunto expressivo de operadores projetados tanto para computação de sistemas de baixo nível quanto para manipulação de dados fluente de alto nível.

Operador de Coalescência Nula: ??

O operador ?? avalia o lado esquerdo e, caso seja nulo ou indefinido, retorna a expressão do lado direito como fallback seguro:

VOX 
let configuracao_usuario = none;
let porta = configuracao_usuario ?? 8080;
println!("Porta em uso: " + (porta as str)); // 8080

Operador de Navegação Segura: ?.

Previne falhas de acesso a propriedades em ponteiros e referências que possam estar vazias:

VOX 
let rua = usuario?.endereco?.rua ?? "Rua Não Informada";

O Operador Pipe: |>

Permite encadear transformações de dados de forma linear e altamente legível, eliminando parênteses aninhados profundos:

VOX 
fn dobrar(n: int) -> int { return n * 2; }
fn adicionar_dez(n: int) -> int { return n + 10; }

let resultado = 5 |> dobrar |> adicionar_dez;
println!("Resultado via Pipe: " + (resultado as str)); // 20
Capítulo 06

Controle de Fluxo Estruturado

O controle de fluxo em Vox é conciso, prescindindo de parênteses redundantes em torno de expressões de teste condicional:

Bifurcação Condicional: if / elif / else

VOX 
let nota: float = 8.5;

if nota >= 9.0 {
    println!("Desempenho: Excelente");
} elif nota >= 7.0 {
    println!("Desempenho: Aprovado");
} else {
    println!("Desempenho: Recuperação");
}

Laços de Repetição: for e while

VOX 
// Iteração sobre intervalo numérico com range sintético:
for i in 1..5 {
    println!("Passo: " + (i as str));
}

// Laço com predicado while:
let mut vida = 3;
while vida > 0 {
    println!("Vidas restantes: " + (vida as str));
    vida = vida - 1;
}
PARTE II
Procedimentos, Dados e Estruturação
Capítulo 07

Funções, Procedimentos e Lambdas

No Vox, funções são cidadãs de primeira classe (first-class citizens). Elas podem ser atribuídas a variáveis, passadas como parâmetros para outras funções e retornadas como resultado.

Assinatura de Funções e Procedimentos

Uma função declara explicitamente os tipos de seus parâmetros e seu tipo de retorno precedido pela seta ->:

VOX 
fn calcular_juros(capital: float, taxa: float, meses: int) -> float {
    return capital * (taxa / 100.0) * (meses as float);
}

// Procedimento: função com efeito colateral sem retorno
fn notificar_usuario(destinatario: str, mensagem: str): void {
    println!("[SMS para " + destinatario + "]: " + mensagem);
}

Expressões Lambda e Closures

Lambdas são funções anônimas declaradas com a sintaxe de barras verticais |args| => expressao. Elas fecham sobre o escopo léxico onde foram definidas:

VOX 
let multiplicador = 3;
let triplicar = |x: int| => x * multiplicador;

println!("Triplo de 7: " + (triplicar(7) as str)); // 21
Capítulo 08

Coleções: Array, Map e Tuplas

O Vox disponibiliza três estruturas essenciais em nível de linguagem:

1. Arrays

VOX 
let mut primos = [2, 3, 5, 7];
primos.push(11);

println!("Primeiro elemento: " + (primos[0] as str));
println!("Total de primos: " + (primos.len() as str));

2. Mapas / Dicionários

VOX 
let cliente = {
    "id": 101,
    "nome": "Carlos Silva",
    "ativo": true
};

println!("Nome do cliente: " + cliente["nome"]);

3. Tuplas

VOX 
fn obter_coordenadas() -> (float, float) {
    return (-23.5505, -46.6333);
}

let coords = obter_coordenadas();
println!("Latitude: " + (coords.0 as str));
Capítulo 09

Orientação a Objetos Moderna

O Vox oferece classes de alta performance focadas em encapsulamento estrito e clareza de dados.

🏛️ Por Que o Vox Eliminou extends?

A herança de classes tradicional (hierarquias profundas com extends) é mundialmente reconhecida como uma fonte de fragilidade arquitetural e acoplamento desnecessário, além de causar object slicing e sobrecarga de tabelas de métodos virtuais (vtable). O Vox adotou a melhor prática moderna de engenharia: Composição sobre Herança, combinada com Traits.

Definição de Classes e Construtor new

VOX — Exemplo de Classe 
class ContaBancaria {
    pub numero: str;
    pub titular: str;
    priv saldo: float;

    pub new(numero: str, titular: str, saldo_inicial: float) {
        self.numero = numero;
        self.titular = titular;
        self.saldo = saldo_inicial;
    }

    pub fn depositar(self, valor: float) -> bool {
        if valor <= 0.0 {
            return false;
        }
        self.saldo = self.saldo + valor;
        return true;
    }

    pub fn obter_saldo(self) -> float {
        return self.saldo;
    }
}
Capítulo 10

Structs, Traits e Blocos Impl

Quando necessitamos de estruturas de dados de baixo custo de memória, declaramos struct. Quando queremos definir contratos de comportamento polimórfico, declaramos trait e implementamos com blocos impl.

VOX — Structs & Traits 
// Registro de dados enxuto:
struct Ponto2D(pub x: float, pub y: float);

// Contrato de interface formal:
trait Desenhavel {
    fn desenhar(self) -> str;
}

// Implementação explícita do comportamento:
impl Desenhavel for Ponto2D {
    fn desenhar(self) -> str {
        return "Ponto(" + (self.x as str) + ", " + (self.y as str) + ")";
    }
}
Capítulo 11

Tipos Genéricos (Generics)

Generics possibilitam escrever algoritmos e estruturas de dados reutilizáveis sem abrir mão da checagem estática de tipos e sem o custo de empacotamento (boxing).

VOX — Generics 
/// Função genérica que inverte pares de qualquer tipo T e U
fn inverter_par<T, U>(primeiro: T, segundo: U) -> (U, T) {
    return (segundo, primeiro);
}

let invertido = inverter_par(100, "OK");
println!(invertido.0); // "OK"
println!(invertido.1 as str); // 100

Gestão de Memória e Concorrência
Capítulo 12

Ownership e o Borrow Checker

O gerenciamento de memória no Vox é governado pelo sistema de Posse Afim (Affine Ownership). Ele garante segurança absoluta em tempo de compilação sem a necessidade de um Garbage Collector pausar a aplicação.

As Três Leis Fundamentais do Ownership

  1. Posse Única: Cada pedaço de memória alocado dinamicamente pertence a exatamente uma variável proprietária (owner).
  2. Liberação Determinística (RAII): No instante exato em que a variável dona sai de escopo (ao fechar das chaves }), sua memória é desalocada automaticamente.
  3. Move Semantics: Atribuir uma variável dona a outra variável transfere a posse definitiva do recurso. O identificador original é invalidado imediatamente.
VOX — Move Semantics 
let recurso = abrir_buffer_pesado();
let destino = recurso; // POSSE TRANSFERIDA (MOVE)

// utilizar 'recurso' agora causará erro de compilação:
// recurso.processar(); // [E0201: Use of moved value]
Capítulo 13

Concorrência CSP e Canais

O Vox implementa o modelo CSP (Communicating Sequential Processes): "Não se comunique compartilhando memória; compartilhe memória comunicando".

VOX — Canais CSP 
let canal = chan_new();

// Dispara corotina em segundo plano:
spawn {
    println!("[Worker] Processando lote de transações...");
    chan_send(canal, "Lote 1 Concluído com Sucesso!");
};

// Thread principal recebe a mensagem com segurança:
let resposta = chan_recv(canal);
println!("[Main] Recebido: " + resposta);
Capítulo 14

Pattern Matching Avançado

O comando match do Vox substitui as antigas e frágeis declarações switch por uma correspondência exaustiva de padrões com checagem rigorosa pelo compilador:

VOX — match 
let codigo_http = 404;

let status_desc = match codigo_http {
    200 => "OK - Requisição bem-sucedida",
    400 => "Bad Request - Dados inválidos",
    404 => "Not Found - Recurso não localizado",
    500..599 => "Internal Server Error - Falha no servidor",
    _ => "Código de status desconhecido"
};

println!(status_desc);
Capítulo 15

Tratamento de Erros: Option e Result

O Vox elimina exceções não tratadas e ponteiros nulos não controlados através de dois tipos canônicos: Option<T> e Result<T, E>.

VOX — Result 
fn dividir(numerador: float, denominador: float) -> Result<float, str> {
    if denominador == 0.0 {
        return err("Divisão por zero não é permitida!");
    }
    return ok(numerador / denominador);
}

let res = dividir(10.0, 2.0);
match res {
    ok(valor) => println!("Resultado: " + (valor as str)),
    err(erro)  => println!("Falha: " + erro)
};
Capítulo 16

Programação Assíncrona (Async/Await)

Tarefas de I/O intensivo em rede e disco são tratadas de forma não bloqueante com async e await:

VOX — Async / Await 
async fn obter_cotacao(moeda: str) -> float {
    // Simula busca em API remota não-bloqueante
    return 5.42;
}

async fn executar() {
    let taxa = await obter_cotacao("USD");
    println!("Cotação obtida: R$ " + (taxa as str));
}

Capítulo 17

Decoradores e Macros Builtin

O Vox fornece decoradores de primeira linha para instrumentação de código sem poluir a lógica de negócios:

VOX — Decoradores 
@timed  // Mede e exibe automaticamente o tempo de execução em microssegundos
@logged // Registra argumentos recebidos e valores retornados
fn processar_faturamento(ano: int) -> int {
    return 1500000;
}

Macros do Compilador

  • println!(...): Formata dados e imprime com salto de linha.
  • format!(...): Retorna uma string formatada sem imprimir.
  • dbg!(expr): Imprime o arquivo, linha, expressão avaliada e seu valor (essencial para depuração).
  • assert!(cond, msg): Garante uma invariante em runtime.
  • panic!(msg): Aborta graciosamente exibindo a pilha de chamadas.
Capítulo 18

Banco de Dados: SQLite Nativo no Vox

A versão v1.0 do Vox traz integração direta e síncrona com SQLite, proporcionando persistência relacional sem a complexidade de drivers externos:

VOX — SQLite 
// 1. Abertura da base de dados:
let db = sqlite_open("banco.db");

// 2. Criação de tabela (DDL):
sqlite_exec(db, "CREATE TABLE IF NOT EXISTS usuarios (id INTEGER PRIMARY KEY, nome TEXT, email TEXT);");

// 3. Inserção de registro (DML):
sqlite_exec(db, "INSERT INTO usuarios (nome, email) VALUES ('Ana Souza', 'ana@vox.org');");

// 4. Consulta estruturada (retorna array de mapas):
let usuarios = sqlite_query(db, "SELECT * FROM usuarios;");
for u in usuarios {
    println!("ID: " + (u["id"] as str) + " | Nome: " + u["nome"]);
}

// 5. Fechamento da conexão:
sqlite_close(db);
Capítulo 19

Arquitetura Corporativa MVC na Prática

A diretiva include "caminho/arquivo.vox"; permite modularizar aplicações de grande escala mantendo coesão e baixo acoplamento:

Camada Arquivo Canônico Responsabilidade
Model cliente_model.vox Encapsula a entidade Cliente e todas as transações SQL com o banco
View cliente_view.vox Renderiza tabelas limpas, menus interativos e formulários para o usuário
Controller cliente_controller.vox Aplica regras de validação (ex: e-mail obrigatório) e orquestra o fluxo
App app.vox Ponto de entrada único que inclui as camadas e inicia a aplicação
VOX — app.vox 
include "models/cliente_model.vox";
include "views/cliente_view.vox";
include "controllers/cliente_controller.vox";

fn main() {
    let ctrl = ClienteController.new("db/clientes_vox.db");
    ctrl.executar();
}
Capítulo 20

Compilação Nativa via C99

O compilador Vox traduz a AST diretamente para C99 estritamente compatível com os padrões POSIX e Win32, gerando executáveis que iniciam em menos de 1 milissegundo:

C99 GERADO (Trecho ilustrativo) 
/* Gerado pelo Vox Compiler v1.0 */
#include "vox_runtime.h"

int main(int argc, char** argv) {
    vox_init();
    printf("Execução nativa de altíssima performance.\n");
    vox_shutdown();
    return 0;
}

Ao executar vox build main.vox -O3, o compilador C aplica vetorização SIMD de instruções, desenrolamento de loops (loop unrolling) e inlining automático, entregando a mesma performance computacional de C puro.
