Manual do Vox Studio RAD

O Vox Studio RAD é um ambiente de desenvolvimento rápido integrado (IDE) de última geração, inspirado no consagrado modelo do Delphi RAD Studio (Athens 12/13) e totalmente adaptado para a linguagem moderna Vox. Este manual abrange em detalhes todos os menus, painéis móveis, propriedades RTTI, eventos e os mais de 50 componentes visuais e não-visuais da paleta.

🏛️ Arquitetura de Projetos (.voxProj)

O ecossistema do Vox Studio RAD adota uma estrutura modular e limpa para organizar os projetos, formulários e lógica de negócio:

📁

Arquivo de Projeto (*.voxProj)

Descritor Principal

Substitui as antigas extensões .dproj por .voxProj. Contém a declaração das plataformas de destino (Windows x64 e Web HTML5), configurações de compilação (Debug / Release), units do projeto, formulários associados e metadados de versão.

🎨

Arquivo de Formulário (*.vxf)

Vox Form Definition

Equivalente ao .dfm do Delphi. Armazena a árvore hierárquica de componentes, coordenadas de layout (Left, Top, Width, Height), regras de alinhamento VCL, vínculos a eventos e valores de propriedades persistidos via RTTI.

📝

Código Fonte da Unit (*.vox)

Lógica da Aplicação

Equivalente ao .pas do Delphi. Contém as definições de classes (class TForm1), atributos privados e públicos, declarações de procedures/functions e métodos manipuladores de eventos (ex: btnCalcularClick()).

💡

Sincronização Bidirecional Contínua (Tecla F12)

Qualquer alteração feita arrastando componentes no formulário visual atualiza instantaneamente o código gerado em Unit1.vox. Da mesma forma, modificar métodos e propriedades no código é refletido no Designer sem necessidade de recarregar a IDE!

🔍 Object Inspector: O Coração do Desenvolvimento RAD

O Object Inspector exibe os metadados RTTI (Run-Time Type Information) do componente em foco, divididos em duas abas: Properties (propriedades persistidas) e Events (disparadores de rotinas).

🏷️ Propriedades Universais (Todos os Controles Visuais)

Propriedade Tipo de Dado Valor Padrão Descrição e Comportamento em Tempo de Execução
Name String (Identificador) ex: Button1 Identificador exclusivo do componente. Torna-se o nome da variável membro na classe da unit (ex: Self.Button1).
Caption / Text String ex: Button1 Texto visível ao usuário (título do botão, etiqueta do label, texto inicial de caixas de edição).
Left, Top Integer (Pixels) 0, 0 Coordenadas X e Y do canto superior esquerdo em relação ao contêiner pai (Form, Panel ou TabSheet).
Width, Height Integer (Pixels) 75, 25 Largura e altura física do controle no formulário.
Visible Boolean True Define se o componente deve ser renderizado e visível ao usuário final.
Enabled Boolean True Habilita ou desabilita a interação com mouse e teclado (apresentando estado esmaecido quando False).
Color TColor / Hex clBtnFace / #ffffff Cor de fundo do controle. Abre a paleta de cores ou seletor hexadecimal no Object Inspector.
Font TFont (Composto) Segoe UI, 9pt Subpropriedades de tipografia: Font.Name, Font.Size, Font.Color e Font.Bold.
Hint / ShowHint String / Boolean "" / False Texto de dica (tooltip) exibido quando o usuário posiciona o cursor sobre o controle.
Cursor TCursor crDefault Formato do ponteiro do mouse (crHandPoint, crHourGlass, crCross, etc.).
Tag Integer 0 Valor numérico livre para o desenvolvedor armazenar identificadores rápidos ou índices customizados.

📐 Regras de Alinhamento VCL: Propriedade `Align`

O clássico sistema de ancoragem e alinhamento responsivo do Delphi é totalmente suportado:

alNone (Padrão)

O componente mantém suas coordenadas absolutas Left e Top fixas no contêiner.

alTop / alBottom

O controle expande sua largura para 100% da área do pai e fixa-se no topo ou rodapé, empilhando novos componentes automaticamente.

alLeft / alRight

O controle assume 100% da altura restante entre o topo e o rodapé, alinhando-se na borda esquerda ou direita.

alClient (Preenchimento Total)

O controle preenche automaticamente todo o espaço útil restante do contêiner. Ideal para DBGrid, PageControl e Memos.

🗄️ Propriedades de Conexão e Dados (FireDAC & DB-Aware)

Propriedade Componentes Que Possuem Função na Arquitetura de Dados
Connection vox_Query, vox_DBTable Seleciona o componente vox_Connection que fornece o pool de conexões SQLite / PostgreSQL.
SQL vox_Query Comando SQL (ex: SELECT id, nome, saldo FROM clientes WHERE status = 1).
Active vox_Query, vox_DBTable Quando True, executa a consulta automaticamente ao iniciar o formulário e preenche o buffer de dados.
DataSet vox_DataSource Aponta para a fonte de dados (ex: vox_Query1), servindo de ponte para os controles visuais.
DataSource vox_DBGrid, vox_DBEdit, vox_DBText Vincula o controle de tela ao vox_DataSource que contém os registros ativos.
DataField vox_DBEdit, vox_DBText, vox_DBMemo Nome da coluna do banco de dados (ex: nome, saldo, email) cujo valor será exibido e editado.

⚡ Aba Events: Disparadores de Rotinas e Ciclo de Vida

Evento Momento do Disparo Assinatura Gerada em Vox
OnClick Clique simples do botão primário do mouse sobre o controle. procedure btnSalvarClick(Sender: TVoxObject)
OnDblClick Duplo clique rápido com o mouse. procedure dbgClientesDblClick(Sender: TVoxObject)
OnEnter / OnExit O controle recebe ou perde o foco de digitação do teclado. procedure edtEmailExit(Sender: TVoxObject)
OnKeyDown / OnKeyUp Pressionamento ou liberação de uma tecla física no teclado. procedure FormKeyDown(Key: Integer; Shift: TShiftState)
OnCreate / OnShow Instanciação física e exibição do formulário na tela. procedure FormCreate(Sender: TVoxObject)
OnClose / OnDestroy Fechamento da janela e destruição dos recursos da memória. procedure FormClose(var Action: TCloseAction)
AfterOpen / AfterPost Disparado após abrir uma consulta SQL ou salvar um registro. procedure qryClientesAfterPost(DataSet: TDataSet)
OnTimer Disparo periódico em intervalos definidos em milissegundos. procedure Timer1Timer(Sender: TVoxObject)
Exemplo de Código Vox Gerado Automaticamente (Unit1.vox) 
// Unit1.vox — Gerado pelo Vox Studio RAD
class TForm1 : TVoxForm {
  public btnBuscar: TVoxButton;
  public edtFiltro: TVoxEdit;
  public dbgClientes: TVoxDBGrid;
  public vox_Query1: TVoxQuery;
  public vox_DataSource1: TVoxDataSource;

  // Manipulador de Evento associado via Object Inspector (OnClick)
  procedure btnBuscarClick(Sender: TVoxObject) {
    let termo = Self.edtFiltro.Text;
    Self.vox_Query1.Close();
    Self.vox_Query1.SQL = "SELECT id, nome, cidade, saldo FROM clientes WHERE nome LIKE '%" + termo + "%'";
    Self.vox_Query1.Open();
  }
}

📦 Catálogo Geral de Componentes da Paleta

O Vox Studio RAD possui uma suíte com dezenas de componentes organizados por categorias lógicas. Utilize a barra de filtro instantâneo abaixo para localizar qualquer controle:

🔘
vox_Button
Equivalente Delphi: TButton
Visual Standard

Botão de comando padrão para disparar ações do usuário. Suporta atalhos com tecla aceleradora (ex: &Salvar torna Alt+S o atalho nativo), estados de pressionamento e estilo moderno.

Propriedades Chave: Caption, Enabled, ModalResult, Default, Cancel, Cursor.
Eventos Principais: OnClick, OnMouseEnter, OnMouseLeave.
📝
vox_Edit
Equivalente Delphi: TEdit
Visual Standard

Caixa de entrada de texto em linha única. Suporta máscaras de digitação, ocultação de senhas com PasswordChar e texto de placeholder descritivo.

Propriedades Chave: Text, MaxLength, ReadOnly, PasswordChar, Placeholder.
Eventos Principais: OnChange, OnKeyDown, OnEnter, OnExit.
🏷️
vox_Label
Equivalente Delphi: TLabel
Visual Standard

Rótulo de texto estático para identificar campos de formulário, títulos de seções ou mensagens de status. Suporta quebra de linha com WordWrap e dimensionamento automático com AutoSize.

Propriedades Chave: Caption, Font, Alignment (taLeftJustify, taCenter, taRightJustify), WordWrap.
☑️
vox_CheckBox
Equivalente Delphi: TCheckBox
Visual Standard

Caixa de seleção booleana para opções que podem ser marcadas ou desmarcadas de forma independente.

Propriedades Chave: Checked (Boolean), Caption, AllowGrayed.
Eventos Principais: OnClick, OnChange.
📋
vox_Memo
Equivalente Delphi: TMemo
Visual Standard

Editor de texto multilinha para anotações, descrições longas, logs de sistema ou código fonte com suporte a barras de rolagem verticais e horizontais.

Propriedades Chave: Lines (TStrings), ScrollBars, ReadOnly, WordWrap.
Eventos Principais: OnChange, OnKeyDown.
📑
vox_MainMenu & vox_PopupMenu
Equivalente Delphi: TMainMenu / TPopupMenu
Barra / Menu Standard

vox_MainMenu gera a barra de menus no topo da janela com menus suspensos aninhados. vox_PopupMenu cria menus de contexto acionados com o botão direito do mouse sobre qualquer componente.

Propriedades Chave: Items (Lista hierárquica de menus e submenus com atalhos).
Eventos Principais: OnPopup, disparos OnClick dos itens.
🔲
vox_Panel
Equivalente Delphi: TPanel
Contêiner Additional

Contêiner versátil com bordas biseladas (Bevel) para organizar outros componentes em áreas distintas da tela, como barras de botões no topo (alTop) ou barras de status.

Propriedades Chave: Align, BevelOuter, BevelInner, BorderWidth, Caption, Color.
🖼️
vox_Image
Equivalente Delphi: TImage
Visual Additional

Renderizador gráfico para imagens raster e vetoriais (PNG, JPEG, WebP, SVG). Suporta ajuste proporcional automático com Proportional e estiramento com Stretch.

Propriedades Chave: Picture (URL ou base64), Stretch, Proportional, Center.
↔️
vox_Splitter
Equivalente Delphi: TSplitter
Layout Additional

Separador redimensionável em tempo de execução. Permite ao usuário arrastar a divisão entre painéis vizinhos (ex: entre a barra lateral esquerda e a área central do aplicativo).

Propriedades Chave: Align, MinSize, ResizeStyle, AutoSnap.
🗂️
vox_PageControl & vox_TabSheet
Equivalente Delphi: TPageControl / TTabSheet
Contêiner Multi-Abas Win32

Gerenciador avançado de abas organizadas em páginas. Suporta adição e remoção de páginas via menu de contexto, clique nas guias superiores para navegação e renderização precisa de contêineres filhos.

Propriedades Chave: ActivePageIndex, Pages, TabPosition (Top, Bottom).
Eventos Principais: OnChange, OnChanging.
📊
vox_ProgressBar
Equivalente Delphi: TProgressBar
Visual Win32

Barra de progresso percentual para indicar o andamento de operações de carga, laços de repetição (loops while / for) ou processamento de relatórios.

Propriedades Chave: Position (0 a 100), Min, Max, Smooth, Step.
🔌
vox_Connection
Equivalente Delphi: TFDConnection
Não-Visual (28px) Data Access

Gerencia a conexão com o banco de dados. Suporta drivers nativos para SQLite (arquivo .db local), PostgreSQL e MySQL, com teste de conexão instantâneo no Object Inspector.

Propriedades Chave: DriverName (SQLite, PG, MySQL), Database, Connected (Boolean), Params.
Eventos Principais: AfterConnect, BeforeDisconnect.
⚡
vox_Query
Equivalente Delphi: TFDQuery
Não-Visual (28px) Data Access

Executor de instruções SQL completas. Permite realizar consultas (SELECT), inserções, atualizações e exclusões. Suporta passagem de parâmetros com a sintaxe :NomeParametro e navegação por registros (First, Next, Prior, Last, Eof).

Propriedades Chave: Connection, SQL, Active, Params, Filter, Filtered.
Eventos Principais: AfterOpen, AfterPost, BeforePost, AfterDelete.
🔗
vox_DataSource
Equivalente Delphi: TDataSource
Não-Visual (28px) Data Access

O elo intermediário da arquitetura bi-direcional. Faz a ponte de ligação entre um conjunto de dados lógico (vox_Query ou vox_DBTable) e múltiplos controles visuais na tela (vox_DBGrid, vox_DBEdit, etc.).

Propriedades Chave: DataSet, AutoEdit (Boolean).
Eventos Principais: OnDataChange, OnStateChange.
📊
vox_DBGrid
Equivalente Delphi: TDBGrid
Data-Aware Visual Data Controls

Tabela de dados profissional com renderização de múltiplas linhas e colunas. Suporta seleção de registros, redimensionamento de colunas, ordenação por clique no cabeçalho, formatação numérica/monetária e paginação automática.

Propriedades Chave: DataSource, Columns, ReadOnly, Options (Linhas de grade, indicador de linha ativa, seleção zebrada).
Eventos Principais: OnDblClick, OnCellClick, OnColEnter.
🧭
vox_DBNavigator
Equivalente Delphi: TDBNavigator
Data-Aware Visual Data Controls

Barra de ferramentas de navegação padrão contendo os clássicos botões do Delphi: First (⏮), Prior (◀), Next (▶), Last (⏭), Insert (+), Delete (-), Edit (✏️), Post (💾), Cancel (✖) e Refresh (🔄).

Propriedades Chave: DataSource, VisibleButtons, ConfirmDelete.
📑
vox_Report & vox_ReportBand
Equivalente Delphi: TQuickRep / TQRBand
Relatórios Reports

Suíte completa para relatórios baseados em faixas (Bands): rbTitle, rbPageHeader, rbColumnHeader, rbDetail, rbSummary e rbPageFooter. Calcula a paginação física da folha A4 e permite exportação direta para PDF de alta resolução.

Propriedades Chave: PageOrientation (Portrait/Landscape), PageSize (A4/Letter), BandType, DataSource.
💲
vox_ReportDBText & vox_ReportSysData
Equivalente Delphi: TQRDBText / TQRSysData
Relatórios Reports

vox_ReportDBText vincula campos dinâmicos da consulta com formatação monetária (ex: R$ #,##0.00) ou de data. vox_ReportSysData insere automaticamente números de página atual/total e data/hora do sistema.

Propriedades Chave: DataField, DisplayFormat, SysDataType (sdPageCount, sdDateTime).
🌐
vox_RESTClient & vox_RESTRequest
Equivalente Delphi: TRESTClient / TRESTRequest
Não-Visual (28px) REST / Web

Consumo de APIs RESTful e Webhooks JSON. Permite disparar requisições GET, POST, PUT e DELETE com autenticação Bearer Token e adaptação de arrays JSON diretamente para um vox_DataSource.

Propriedades Chave: BaseURL, Method, Resource, Params.
Eventos Principais: AfterExecute, OnError.

🚀 Compilação & Geração do Sistema Web

O Vox Studio RAD possui um pipeline de compilação integrado que transforma o projeto visual diretamente em uma aplicação web pronta para produção:

1. Análise Semântica do Formulário

O compilador analisa a árvore de controles .vxf, resolvendo o alinhamento VCL responsivo e mapeando os tipos para classes web padronizadas.

2. Transpilação do Código Vox

Os métodos e regras de negócio da Unit1.vox são validados pela semântica da linguagem Vox e transpilados com tipagem gradual e suporte a SQLite.

3. Empacotamento para a Pasta dist/

Gera o index.html, os estilos compilados em CSS e o script da aplicação executável em qualquer servidor web ou nativo via Node/Electron.

⭐

Atalho de Compilação Rápida

Basta clicar no botão Build Web na barra de ferramentas ou pressionar F9 para executar a aplicação imediatamente na porta local com abertura automática no navegador!
